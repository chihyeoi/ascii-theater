개인정보처리방침

시행일: 2026년 11월 12일

ASCII 상영관(https://chihyeoi.github.io/ascii-theater/, 이하 "사이트")은 친구들끼리 AI 프롬프트와 그 결과물을 나누기 위해 만든 개인 비영리 사이트입니다. 이 문서는 사이트가 어떤 정보를 왜 받고, 어떻게 보관하는지 설명합니다.

1. 받는 정보

  • 구글 로그인 정보: 상영작을 올리려고 구글로 로그인하면 구글 계정의 이름, 이메일 주소, 고유 식별자를 받습니다. 비밀번호는 받지 않습니다.
  • 직접 올린 내용: 별명(선택), 상영작의 제목, 한 줄 소개, 프롬프트, HTML 코드, 올린 시각.

로그인하지 않고 프롬프트를 복사하거나 붙여넣기 상영만 하는 경우에는 어떤 개인정보도 받지 않습니다. 붙여넣은 코드는 내 브라우저 안에서만 실행되고 서버로 보내지지 않습니다.

2. 쓰는 목적

  • 로그인한 사람만 상영작을 올리고, 자기가 올린 것만 지울 수 있게 하기 위해
  • 내가 올린 상영작을 나만 지울 수 있게 구분하기 위해
  • 도배나 장난성 글을 막기 위해 (한 사람당 하루 올리기 횟수 제한)

광고, 마케팅, 판매에는 쓰지 않으며 제3자에게 제공하지 않습니다.

3. 보관 장소와 기간

정보는 데이터베이스 서비스인 Supabase에 저장됩니다. 상영작은 올린 사람이 내리거나 운영자가 삭제할 때까지 보관됩니다. 계정 정보는 삭제를 요청하면 지체 없이 지웁니다.

4. 공개되는 정보

상영작의 제목, 소개, 프롬프트, HTML 코드, 올린 사람이 직접 정한 별명(정하지 않으면 "익명")은 사이트를 방문하는 누구나 볼 수 있습니다. 구글 계정 이름과 이메일 주소는 공개되지 않습니다.

5. 내 정보 지우기

내가 올린 상영작은 사이트에서 내리기 버튼으로 바로 지울 수 있습니다. 계정 정보까지 지우고 싶으면 아래 연락처로 요청해 주세요.

6. 연락처

문의와 삭제 요청은 GitHub Issues로 남겨 주세요.
